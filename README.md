# PR 2 Analyzer

## 📊 Project Overview
PR 2 Analyzer is an advanced Microsoft Excel analytics project focused on transforming raw sales data into meaningful business insights using dashboards, pivot tables, charts, regression analysis, and Excel automation features.

This project demonstrates practical Business Intelligence (BI) concepts using Excel tools and formulas.

---

# 🎯 Objective
The objective of this project is to:
- Analyze customer transaction data
- Generate business insights
- Create interactive dashboards
- Perform statistical and predictive analysis
- Visualize KPIs using professional charts
